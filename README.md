# AI-Era-Guide
AI-Era-Guide（AI时代指南）. An independent personal exploration repository. We face the impacts of old order, keep calm, explore the coexistence of humans and AI, and build new order rationally. No panic, open iteration.
我想发起一个开放项目，叫作 “AI时代生存指南”。

本项目为个人独立探索，非官方项目。我们正视旧秩序受到的冲击，主张在动荡中保持冷静，理性探索人与 AI 共生的新秩序，沉淀思考与实践方向。拒绝恐慌叙事，持续迭代。它的核心宗旨是：在 AI 时代的混乱中构建秩序，包括理解外部世界的秩序，也包括内心的秩序。

AI 的发展正在冲击我们熟悉的判断。过去，我相信通过努力学习、提高能力，就能凭借自己的劳动和创造为社会作出贡献，获得尊重与认可，感到自己被需要。数学一直是我沿着这条路前进的支点。当 AI 开始进入数学研究，我也开始追问：如果机器能够完成我们引以为豪的工作，我们应该怎样安排未来？努力的方向、社会中的位置和价值感，又该怎样重新建立？

这些问题让我感到，原有的确定性正在松动，新的方向还没有清晰起来。但我也承认：**我可能高估了 AI 发展的速度和冲击，也可能高估了一份指南能够发挥的作用。** 我的不安无法证明未来一定危险，别人的淡定同样无法证明变化不会发生。我们需要把这些判断拿出来共同检验。

这个项目希望持续研究三个相互关联的问题：AI 正在发生什么变化，这些变化怎样影响教育、科研、职业和社会，以及我们现在能够采取什么行动。它也会认真讨论人的处境：面对不确定，怎样维持生活、理解自己的价值，怎样面对失去方向和不再被需要的担忧。

其中一个重要方法，是建立类似气象预警的观察与应对框架。我们持续收集能力、制度和现实生活中的变化，写清楚判断依据、不确定性和不同解释，再提出与证据相称的准备建议。每一项预警都需要后续复查，也允许下调、撤回和承认误报。逐步积累记录，才能知道自己的框架到底有没有用。

我希望这个过程能够帮助人更清醒。风险值得正视，包括那些后果严重、目前又难以确定的风险。很多事情超出个人控制范围，但我们仍可以寻找策略、保留选择、帮助彼此。越是危险、越是不确定，越需要冷静。恐惧本身解决不了问题，我们需要把担忧转化为能够分析的问题和能够采取的行动。

内心的秩序，也建立在这里。我无法保证每次预测都正确，但可以逐渐形成一套可信赖的方法：观察事实、检查证据、推敲逻辑、作出选择，再根据反馈修正。判断错了，有办法发现；计划失效了，有办法调整；暂时没有答案，也能继续生活和探索。对这套方法的信任，可以成为变化中的支点。

项目计划在 GitHub 上公开，持续迭代，收集不同人的思考、经验、资料和反例。我希望参与者能够补充、纠错、提出不同判断，也能够在明确的开放许可下复制、修改和继续发展。分歧可以保留，贡献需要得到认可，内容的可信度靠来源、论证和长期修订逐渐建立。

我是一名数学专业的大学生，有很多领域并不了解，也不知道所有问题该怎样解决。我能承担的是先整理已有材料，提出自己真正关心的问题，连接愿意参与的人，并尽力维护这个项目。后续的内容需要更多有经验、有能力的人共同完成。我也无法保证自己永远有精力做下去，因此希望它的成果能够被别人接续。

我想在评选演讲中公开这个想法，因为这正是我此刻真实的思考和选择。我希望讲出自己的困惑，也讲出自己准备采取的行动，让有相同关切的人知道这个项目。能否获奖，对我而言已经没有那么重要。

**我希望“AI时代生存指南”能够让参与者获得一点更清楚的判断、更具体的行动方向，以及面对变化时内心的稳定。** 先把自己能够做的部分做出来，再让它在共同探索中逐渐成长。
