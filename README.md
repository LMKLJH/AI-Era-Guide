# Guide-to-the-AI-Era
Guide to the AI Era（AI时代指南）. An independent personal exploration repository. We face the impacts of old order, keep calm, explore the coexistence of humans and AI, and build new order rationally. No panic, open iteration.
本项目为个人独立探索，非官方项目。我们正视旧秩序受到的冲击，主张在动荡中保持冷静，理性探索人与 AI 共生的新秩序，沉淀思考与实践方向。拒绝恐慌叙事，持续迭代。
