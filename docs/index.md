## 项目宗旨

AI 的发展正在冲击我们熟悉的判断。我们希望把这些变化放进一个可以持续讨论、验证和修订的框架中。

本项目不预设唯一未来。我们区分事实、专家观点、推演与预测，记录判断依据，欢迎补充证据、提出反例和修正结论。

## 核心研究链条

**智能发展 → 生产力变化 → 生产关系调整 → 教育与制度变革 → 个体行动**

## 参与原则

- 观点尽量提供来源和推理过程；
- 尊重分歧，不把预测写成事实；
- 允许纠错，保留重要版本；
- 将焦虑转化为可验证的问题和实际行动。
