# 个体应对：思想纲领

## 核心原则

1. 从人性需求出发判断价值，关注需求强度、供给、稀缺性与支付能力。
2. 理解智能工业化趋势，主动学习和使用 AI。
3. 要么加入 AI 阵营，要么进入 AI 相对难以替代、且具有真实需求的领域。
4. 不把未来押在单一预测上，保留多条路径和调整空间。
5. 从可控因素出发：学习、选择、行动、合作、健康和风险管理。
6. 把焦虑转化为可验证的问题和实际行动。
7. 认真生活，持续成长，不把当下全部献祭给未知未来。

## 决策检查

- 我解决的是真实需求吗？
- 这项能力是否容易被 AI 规模化供给？
- 我是否拥有信任、客户、渠道、组织或现实资源连接？
- 如果 AI 发展更快或更慢，我的选择是否仍有价值？
