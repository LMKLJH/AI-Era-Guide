## 4.1 思想纲领 {#principles}

本文依据[《AI时代生存指南》思想纲领 V1.1（2026年10月）](/04-research/#principles)整理。保留原稿的核心假说、推理链条与行动原则，作为持续讨论和修订的起点。

> 从物理规律推演技术趋势，从人性需求寻找价值，从稀缺性分析经济回报，从利益结构研究制度变化，最终制定个人生存策略。

### 一、出发点：机器智能的结构性优势

**机器智能具备突破人类生物智能上限的结构性优势。**这是整份纲领的起点，也解释了为什么我们需要把 AI 的影响放到长期尺度上研究。

原稿列出人类大脑的六个生物学硬约束：

| 约束 | 具体含义 |
| --- | --- |
| 计算规模 | 神经结构难以大规模扩充 |
| 计算速度 | 生物电化学信号传递速度有限 |
| 持续运行 | 需要睡眠休息，无法24小时高强度思考 |
| 信息存储 | 记忆容量、精度和提取速度有限 |
| 复制能力 | 培养高级智力劳动者需要多年 |
| 并行协作 | 知识交换受语言和组织成本限制 |

人积累一项高级能力，往往需要多年学习；向另一个人传递这种能力，还要经历一次漫长的培养。机器计算系统则可以通过工程投入扩大规模、部署副本和组织并行计算。**智能的增长方式、复制方式和使用方式，因此可能发生根本变化。**

原稿的核心假说是：

> 在智能能够由非生物计算系统实现、算法持续进步的条件下，机器智能具备突破人类个体生物智能上限的结构性优势。
>
> 这一优势可能形成长期、持续的技术替代动力。

这意味着，个人的长期规划不能只依赖“某项能力永远只能由人完成”。需要继续追问：如果机器也能完成，而且能够低成本复制，我的位置会怎样变化？

结构优势也有实现条件。算力扩充需要芯片、能源和资金，复制与协作有工程成本，更多计算未必自动带来可靠能力。这一假说提出长期研究方向，并没有给出全面超越人类的具体年份。

### 二、七层推理：从技术变化走到个人选择

| 层次 | 需要追问的问题 |
| --- | --- |
| 物理规律 | 生物大脑受到哪些约束？机器计算可以怎样扩展？ |
| 技术演化 | 机器智能会突破哪些能力边界？能力、成本与可靠性如何变化？ |
| 稀缺性变化 | 智力服务供给扩大后，哪些技能更容易获得，哪些资源仍然稀缺？ |
| 经济价值重构 | 价格、议价权、收入和收益归属如何改变？ |
| 社会制度调整 | 教育、科研、职业评价、产权与分配制度承受什么压力？ |
| 个人生存战略 | 怎样参与新的生产过程，或进入仍有真实需求和稀缺性的环节？ |
| 精神与人生价值 | 怎样保留意义、信念、关系和自主性？ |

每一步都需要检查实际条件。例如，完成任务的成本下降后，需求也可能扩大；技术能够替代某项工作，组织未必立即取消岗位。研究这条链，是为了找出变化经过哪些环节传到自己身上，并据此行动。

### 三、需求与稀缺性：能力强，为什么未必回报高？

原稿的判断是：**需求决定价值的基础，稀缺性影响溢价。**具体市场回报还受到替代品、生产成本、竞争和控制权影响。

过去，高级智力能力依附于少数专家，培养慢、供给少，因此往往拥有较强的议价能力。如果 AI 能够大量提供同类服务，即使这项工作仍然重要，完成它的人也可能更难获得过去的报酬。

判断一个职业或研究方向，至少要问五个问题：

1. **需求有多大？**谁需要这项成果，愿意付出什么？
2. **AI成本多低？**达到可用质量需要多少费用、时间和监督？
3. **新增需求多少？**成本下降会不会让更多人开始使用？
4. **什么仍然稀缺？**瓶颈会转向哪些资源、条件或能力？
5. **谁拥有控制权？**谁掌握系统、客户、产权和收益分配？

这些问题比单独问“AI能不能做”更接近个人的收入、岗位与发展机会。

### 四、从人的需求寻找方向

| 需求 | 主要内容 |
| --- | --- |
| 生存 | 食物、住房、能源、医疗与基本生活条件 |
| 安全 | 健康保障、秩序、稳定与风险控制 |
| 情感 | 亲密关系、陪伴、理解与关爱 |
| 社会 | 归属、地位、尊重、认可与竞争 |
| 自由 | 自主、选择权、隐私与控制权 |
| 精神 | 意义、信念、希望与精神力量 |
| 体验 | 艺术、娱乐、旅行、审美与独特经历 |
| 探索 | 数学、科学、创造与理解世界 |

原稿还区分两种稀缺：一种受到物理资源、能源和生产能力限制；另一种来自地位、排名、独特性和相对竞争。生产能力提高可能缓解前者，却不会自动消除后者。

因此，物质和智力服务丰富，不等于人的需求消失。研究机会时，需要看清需求是否真实存在，也要看清满足它的方式是否已经变得容易复制。

### 五、数学人的处境：科学价值与职业回报分开看

**数学的科学价值依然巨大，但数学劳动的经济稀缺性可能持续下降。**

原稿提出，常规计算和证明、充分形式化的问题求解、标准化算法设计、部分数学建模与分析，以及依赖重复性推理的科研流程，都值得持续观察。

对数学专业学生来说，“数学很重要”还不足以回答自己的职业问题。更具体的问题是：社会需要什么数学成果？谁来生产更有效？自己能够参与哪个环节，又能获得怎样的回报？

原稿列出的转型研究方向包括 AI 系统与智能体、工业与能源优化、实验科学与计算研究、机器人与复杂系统，以及可靠性工程与安全关键系统。这些是需要结合项目、岗位与个人条件检验的方向，不能直接当成就业保证。

升学、就业和科研方向的选择，都应把 AI 的长期影响纳入考虑。同时保留数学探索本身的内在价值，不要求每一份热爱都由市场回报证明。

### 六、个人战略：双路线与真实需求

原稿提出一个鲜明的行动主张：

> **要么加入AI阵营，要么进入AI最难替代的阵营。**

第一条路线，是参与 AI 技术和生产力的发展：基础研究、应用开发、智能体、自动化系统、产业融合，以及利用 AI 完成科研、工程和产品开发。

第二条路线，是从人的需求出发，研究受物理条件、信任、产权和责任约束的价值环节：能源与关键资源、基础设施、现实生产系统、长期关系、社会组织，以及精神需求与共同体。

两条路线可以结合：**利用 AI 扩大生产能力，同时参与满足真实需求、具有持续稀缺性的价值环节。**

“难替代”需要不断重新判断。信任、责任或组织能力，都不能仅凭名称就被认定为永久安全区。要观察具体场景里谁被需要、谁承担后果、谁能够获得收入。

### 七、生存原则：保留调整方向的条件

在技术发展速度与社会调整速度都不确定时，原稿提出七项风险防御原则：

1. 保障基本收入与生活条件。
2. 尽可能建立合理的经济储备。
3. 控制不可承受的债务和职业风险。
4. 学习使用 AI，持续跟踪其能力进步。
5. 减少对单一技能、行业和收入的依赖。
6. 积累可迁移能力、项目经验与社会关系。
7. 根据技术与产业变化动态调整方向。

这些原则共同指向**选择权**：即使某项预测错了，或者原有方向受到冲击，仍然有时间、资源和能力调整。

### 八、精神价值：工作被替代后，缺失的是什么？

原稿指出，现代工作同时承担五种功能：提供收入、确立身份和地位、形成成就感、安排生活秩序与长期目标，以及建立社会关系。

因此，职业受到冲击时，人失去的可能远不止一份收入。一个人通过努力提高能力，为别人解决问题，得到尊重与认可，由此感到自己被需要。**如果这些能力不再稀缺，“努力—贡献—认可—意义”的联系就可能动摇。**这是结合项目讨论对原稿五种工作功能的进一步展开。

原稿据此提出：随着物质生产与智力服务日益丰富，人对意义感、情绪稳定、精神力量、信念、归属感和自主性的需求，可能更加突出。

这也是指南需要研究真实关系、长期信任、心理韧性和共同体的原因。讨论收入保障的同时，还需要讨论人怎样参与社会、获得认可，以及过上自己愿意过的生活。

### 九、七条基本原则与终极问题

1. **技术演化原则：**机器智能具有突破人类生物智能约束的结构性优势。
2. **需求原则：**人类需求是经济活动的根本出发点。
3. **稀缺性原则：**持续研究 AI 怎样改变不同能力与资源的稀缺程度。
4. **制度演化原则：**追踪生产力变化对教育、科研、职业、产权和分配的压力。
5. **双路线生存原则：**参与 AI 生产与研究，或进入较难替代的价值环节，并持续检验。
6. **精神价值原则：**重视意义、情绪、信念、真实关系与自主性。
7. **生存与选择权原则：**优先保障经济安全，积累调整方向的条件。

原稿最后追问：如果 AI 能完成绝大多数智力劳动，机器人又承担大量体力劳动，人是否仍需要出售劳动换取生活资源？财富如何分配？人怎样获得成就感？普通人怎样保留对技术、资源和生活的自主权？

> 不把未来押注在AI永远无法超越人的能力上，而是研究在AI持续提高的各种可能世界中，人应当如何维持生存、参与财富分配、掌握选择权，并重新定义有价值的生活。

### 在变化中建立秩序：2026年11月23日补充

[2026年11月23日演讲研究整理](/04-research/math-civilization-2026-11-23)进一步提出：不把个人未来押在某项能力永远不可替代的判断上，也不把最坏情景当成已经发生的现实。观察模型在真实任务中的能力、使用成本、可靠性与实际采用情况，再追踪岗位和制度是否变化。

**内心的秩序来自一套能检查、能修正、能行动的方法。**说清依据，承认未知，给重要判断设置重新检查的条件；把担忧变成一个可以推进的问题，同时保留正常生活。

人的尊严不必靠比机器更聪明来证明。职业回报、公共分配、真实贡献和人生意义需要分别研究，并在生活中重新连接。这也是指南组织共同讨论、持续迭代的理由。

### 生活优先，预案兜底

AGI预案主张同时认真生活与轻量准备。原稿用“90%生活成长、10%风险预备”表达取舍（[AGI 风险 PPT](/04-research/#agi)）。这里保留为个人精力安排的提醒，不作为精确最优比例，更不作为投资配置。

承认风险，持续更新认知；同时学习、工作、经营关系和体验生活。光恐惧没有用，也不应让尚未发生的情景吞没当下。
