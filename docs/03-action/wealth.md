# 4.3 个人财富与风险管理

## 先保障生存，再争取发展
思想纲领提出保障基本收入与生活条件，建立与自身情况相称的储备，控制不可承受的债务和职业风险，减少对单一技能、行业与收入的依赖（[《思想纲领 V1.1》](/04-research/#principles)）。

储备服务于调整能力，不要求为某个未经验证的未来放弃全部生活。经济安排需要结合实际支出、家庭责任与可承受损失，本项目不设统一金额，也不作具体资产推荐。

## 两类风险分别准备
AGI材料区分技术失控与社会分配风险。前者涉及权限、运行与基础设施，后者涉及工作、收入和资源归属。个人可以维护基本生活、联络、资料与转换选择，宏观问题仍需公共制度回应。

不押注单一结局，不购买无法承担的高价末日装备，不因网络预测仓促辞职或脱离现实生活。具体应急行动放在4.6，与可核实情况和当地安排一起判断。
