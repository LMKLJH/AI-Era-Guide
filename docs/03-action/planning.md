# 4.6 个人行动与长期规划

## 把学习、实践与反馈接起来
沿着思想纲领，持续学习AI、跟踪能力与产业变化，积累可迁移能力、项目经验和社会关系。根据新材料调整方向，同时保留基本生活和选择空间。

报告给出的行动方法是寓教于做、知行合一。走进真实问题，完成一轮交付，接收具体反馈，再问能否做得更好。讨论进一步强调需求访谈、尽早交付原型和持续迭代（[熊辉报告](/04-research/xiong-hui-report)、[教育与创业讨论转写](/04-research/discussion-source)）。

学习可以从知识框架开始，诊断缺口，补充必要内容，再检验是否能够独立解释和使用。选择环境时，检查是否存在专业反馈、合作伙伴与实际机会。没有这些条件，忙碌未必形成持续成长。

## 极端风险的分级预案
原AGI材料提出黄、橙、红、黑四级，用来把担忧转成分阶段行动（[AGI 风险 PPT](/04-research/#agi)）。这是个人情景框架，尚未验证预警精度，也不是官方等级。AI限流、监管变化或一次系统故障，不能单独确认灾难；应核实事实，结合实际服务状况与当地应急信息。

原稿包含不同周数和月数的储备，以及离线、撤离等设想。本项目不把它们改写成适合所有人的固定指令。储备要结合资源、轮换与实际需要；撤离取决于具体威胁、路线和指引，断网也可能使人失去求助信息。

## 行动边界
保留原材料的几条底线：不把个人对抗AGI作为方案，不自制EMP、爆炸物等危险装置，不盲目购买高价末日产品，不传播未经核实的灾难消息，不把全部人生押在一个判断上。

预案的目标是减少临时慌乱，保持可执行的安排。能力跃升、隐蔽失效与社会动荡都属于需要研究的情景，不能仅凭想象确定发生时间。日常仍以认真生活、成长与实际合作为主。
