# 4.5 情绪价值、精神力量与人际关系

思想纲领把精神需求、情绪稳定、真实关系、信念、希望和自主性列为重要主题（[《思想纲领 V1.1》](/04-research/#principles)）。这些需要既存在于个人生活，也存在于社群和共同事业。

本项目强调，危机意识应帮助行动，持续恐惧本身不能改善处境。可以承认失落，给担忧安排有限的观察与准备，再把时间放回学习、健康、关系和实际项目。

AGI预案强调不献祭当下。若最坏情景没有发生，生活没有被荒废；若外部环境恶化，已有关系、能力和共同经历也能成为支持。预案只能增加准备，不能保证任何情景下都安全。

真实关系需要长期相处与承担。共同体可以提供归属与合作机会，也应允许不同生活目标。关于具体心理和人际方法，后续有材料再补。

## 内心的秩序：知道自己怎样判断和修正

本项目所说的“相信系统、相信逻辑框架”，指向一套能接受检验和修订的方法。具体判断可能错，框架也可能漏掉关键因素。可靠之处在于：知道依据是什么，什么情况需要改判，改判后采取什么行动。

“旧秩序摇摇欲坠”表达了一种切身感受。具体到升学、教职和收入，仍要看哪些规则确实改变，哪些仍在运作，哪些只是担忧。把三者分清，能帮助自己继续生活和决定。

方向不清时，可以先保留几件确定值得做的事：身体健康、基本生活、专业训练、真实合作、有限而持续地了解AI。不必等想通整个文明的未来，才允许自己开始今天。
