# 3.4 社会制度、权力与财富分配

思想纲领提出：当智力服务日益廉价，劳动与收入之间的关系可能变化，需要研究财富怎样在资本、劳动者和公众之间分配（[《思想纲领 V1.1》](/04-research/#principles)）。

AGI预案把它列为独立于对齐的危机情景：即使系统安全，自动化资产集中、劳动报酬下降与收入渠道不足，仍可能使普通人承压（[AGI 风险 PPT](/04-research/#agi)）。这是条件性担忧，不代表生产与消费必然完全脱节。

需要继续积累的材料包括：教育、就业、产权与社会保障怎样调整，普通人怎样参与收益，以及如何保留对资源、技术和自身生活的选择权。本项目不先写成制度结论。
