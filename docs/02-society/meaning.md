# 3.6 人类社会的意义危机

## 工作同时承担多种功能
思想纲领指出，工作提供收入和资源，也形成身份、地位、成就、自我价值、生活秩序、目标与社会关系（[《思想纲领 V1.1》](/04-research/#principles)）。劳动需求变化时，这些功能可能一起受到影响。

对本项目发起人而言，被需要感有一条具体来源：努力提高能力，通过劳动、智力与创造作出贡献，获得社会尊重与认可。若同等成果能由AI便宜获得，努力提高与社会需要之间的联系就可能减弱。

收入支持、兴趣和亲密关系各有作用，却未必完整补偿通过真实贡献获得认可的体验。意义危机需要同时研究个人生活与社会参与渠道，不能只要求个人改变心态。

## 物质与智力服务丰富后的精神需求
纲领提出，意义、情绪稳定、精神力量、信念、归属与自主性可能更加突出。真实关系、长期信任与共同体值得持续关注。

这个判断作为研究假说保留。物质丰富不必然使每个人空虚，精神需求也不自动转化为高收入。需要从具体人的生活与需求继续积累材料。

## 真正担忧的是：我的努力还被需要吗

“我通过努力提高能力，用劳动、智力和创造贡献社会，再获得尊重与认可。”这是一条真实的意义来源。当成果不再稀缺，断裂的可能是整条联系：努力仍然存在，能力也在增长，但社会不再需要购买这份劳动。

说“以后可以多享受生活”，未必回答了这个问题。被照顾、被喜欢、被雇用、被尊重、因贡献而被需要，是不同的体验。用人为制造的低效率保留一个岗位，也未必能让人相信自己的贡献真实必要。

## 承认目前没有保证

在“AI全面超过人类”的假设里，没有充分理由保证每个人原有的专业身份和社会地位都能保留。对这种损失的担忧值得认真讨论。与此同时，失去市场稀缺性，也不能推出一个人的生命应当失去权利与尊严。职业回报与人的基本地位，需要分别论证。

因此，意义问题也有制度层面：普通人有没有参与公共决定的渠道，有没有能影响结果的真实职责，能否在教育、社区、照顾和共同事业中得到实际参与机会？这些渠道能否满足不同的人，仍需实践检验，不能承诺一套统一答案。
