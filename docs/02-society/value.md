# 3.1 人性需求、价值与稀缺性

## 从人需要什么开始
思想纲领把需求作为分析价值的起点（[《思想纲领 V1.1》](/04-research/#principles)）。需求包含多个维度，不能只按生产效率理解：

| 需求 | 内容 |
| --- | --- |
| 生存与安全 | 基本生活、健康、稳定、风险控制 |
| 情感与社会 | 亲密、理解、归属、尊重、认可 |
| 自由与精神 | 自主、隐私、意义、信念、希望 |
| 体验与探索 | 审美、经历、数学、科学、创造 |

一种能力的市场回报，还取决于有效需求、供给约束、替代品、成本和竞争。社会需要某项成果，不必然意味着每个能提供它的人都获得原有报酬。当AI扩大供给，稀缺性与议价权就可能变化。

## 绝对稀缺与相对稀缺
纲领区分物理资源和生产能力限制形成的稀缺，以及地位、排名、独特性和竞争形成的相对稀缺。生产能力提高，可以缓解部分资源短缺，却不自动消除对尊重、认可和独特体验的追求。

职业和产业判断可以围绕五个问题展开：需求多大，AI成本多低，新增需求多少，什么仍稀缺，谁拥有控制权。这里提供分析入口，具体结论需要后续材料。

## 从工程师红利到“人物红利”
熊辉用“人物红利”描述组织人才、技术与资源的作用，并提出“做平台、建系统、定标准、创品牌”（[熊辉报告](/04-research/xiong-hui-report)）。平台连接机会，系统维持协作，标准降低沟通和使用成本，品牌通过持续兑现建立信任。

这种思路也适用于学术和公共活动：组织共同研究、维护可复用材料、建立讨论和核验规则，都可能帮助多人创造价值。需要同时观察谁控制入口，以及参与者是否有自主空间。
