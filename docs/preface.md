# 前言·AI时代的认知与行动原则

我们无法决定时代如何变化，但可以决定如何认识时代、如何准备，以及如何行动。

## 六项基本行动准则

1. **承认不确定性。**AI 未来难以准确预测，顶尖专家也有认知局限。保持开放，避免把判断提前写成定局。
2. **区分可控与不可控。**精力优先投入能够控制和影响的事。对宏观趋势保持关注、做好准备，并接受仍有无法掌握的部分。
3. **坚持可验证与决策相关。**重视证据、反馈和修正。研究能核查、能指导选择的问题，减少无休止猜测。
4. **主动建立认知框架。**学习 AI、收集信息、分析趋势，根据新证据更新。在混乱中建立自己的秩序。
5. **将焦虑转化为行动。**保持适度危机意识，准备职业、经济和心理方面的调整。只有恐惧无法改善处境，应把担忧落实到有限任务。
6. **重视身心健康与长期发展。**维持生活节奏，照顾身体与社会关系，积累多方面能力，保留长期行动能力和选择权。
