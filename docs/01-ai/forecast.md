# 1.4 AI 能力边界与未来预测

## 先建立观察方法

现有素材不足以给出可靠的能力时间表。本节先记录项目的研究办法：像预警工作一样持续观察，说明依据和触发条件，再根据新证据调整。这里的类比不代表我们已经拥有气象预报的模型、数据和准确率。

把“AI很强”拆成具体问题。例如数学研究要分别观察选题、猜想、证明、核验和理论组织，还要区分演示案例、可重复表现与独立研究流程。一次成功不能自动代表所有领域都已解决。

## 能力变化怎样影响我的决定

| 要记录什么 | 具体要求 |
| --- | --- |
| 判断 | 写明任务和范围，避免只写“全面超过人类” |
| 依据 | 保存原始材料，标出演示、独立验证或个人体验 |
| 失效条件 | 什么证据会使自己降低或撤回判断 |
| 现实影响 | 哪种招聘、培养或工作流程变化已经发生 |
| 行动 | 先选择可调整的学习或项目安排 |
| 复查 | 到约定日期对照结果，保留原判断和修订原因 |

具体日期预测可以提出，但必须作为预测留档。既要能提高警觉，也要能降低警觉；只会升级的预警框架，会把所有消息都读成危险。

本页来自项目发起人的预警框架设想及[项目介绍](/04-research/#project)的可验证原则，尚未建立经过校准的预测模型。
